# /new-story $ARGUMENTS

첫 번째 인자는 난이도 단계(1~5), 나머지는 주제다. **오리지널** 이야기 팩 초안을 만든다.
먼저 `CLAUDE.md` 의 학습 철학 6원칙과 `src/content/schema.ts` 를 읽는다.

## 순서
1. 기존 팩(`content/packs/`)을 훑어 번호·등장인물·이미 쓴 주제를 확인한다.
2. 팩 id 를 정한다: `<stage 약어>-g<학년>-<두 자리 번호>-<영문-주제>` (예: `elem-g2-07-snow-day`).
3. `npm run pack:new -- <packId>` 로 템플릿을 만든다.
4. `pack.json` 과 `story.json` 을 아래 기준으로 채운다.
5. `npm run pack:art -- <packId>` 로 placeholder 장면 그림을 만든다.
6. `npm test` 로 스키마·"한국어 없음" 검사를 통과하는지 확인한다.
7. `npm run audio:todo -- <packId>` 로 녹음할 목록이 나오는지 확인하고, 이야기 요약과 다음 단계(`/make-audio <packId>`)를 한국어로 보고한다.

## 레벨별 기준
| level | 문장 수 | 문장 길이 | 새 단어(words) | 시제·문형 |
|---|---|---|---|---|
| 1 | 8~14 | 3~9 단어 | 8~10 | 현재형, 짧은 대화 |
| 2 | 10~15 | 4~11 단어 | 10~12 | 현재형 + 쉬운 과거 조금, and/but |
| 3 | 14~20 | 6~14 단어 | 12~15 | 과거형, because/when |
| 4 | 18~26 | 8~18 단어 | 14~18 | 복문, 감정·이유 묘사 |
| 5 | 22~32 | 10~22 단어 | 16~20 | 비문학·직업 상황 포함 |

## 내용 규칙
- **한국어 금지**: story.json / pack.json 어디에도 한글을 쓰지 않는다. 한국어 뜻 필드도 만들지 않는다.
- **오리지널**: 시중 그림책·영화·게임의 줄거리, 캐릭터, 고유명사를 쓰거나 모방하지 않는다.
  등장인물은 이 게임의 인물(Mina, Leo, Ava, Ms. Harper, Mr. Page)이나 새 오리지널 인물만.
- **장면**: 4~6개. 장면마다 `objects` 3~4개(탭하면 단어를 들려줄 사물, 이모지 + 좌표 0~100).
- **대화 중심**: 문장의 40% 이상은 인물의 말. `speaker` 와 `voiceStyle` 을 알맞게 지정한다.
- **words**: 이야기 문장에 실제로 나오는 단어만. `easyEnglish` 는 그 단어보다 쉬운 말로 5~9 단어, 그림이 떠오르게.
- **phrasePocket**: 5~10개. 아이가 실제로 말할 수 있는 표현 덩어리(chunk)이고, **이야기 문장 안에 그대로 나와야** 한다.
- **nativeText**: 2~4개 문장에 구어체(gonna, wanna, ya 등) 버전을 넣는다.
- **theme**: 일상 장면이면 `daily`, 모험·상상이면 `adventure`.
- **talk**: ⑤ Use It! 대화 설정. `npc`(leo/ava/mrbooks/harper), 한 줄 `scene`, 질문으로 끝나는 `opener`.
- 어린이에게 안전한 내용만(폭력·공포·광고·실존 인물 없음). 따뜻한 결말.
