# 아트 바이블 — My American School Quest

화면 전체가 "하나의 게임"처럼 보이도록, 새 화면·에셋을 만들 때 이 문서를 기준으로 삼는다.
코드의 실제 값은 `src/config/theme.ts`(3D 색·조명)와 `src/index.css`(UI 토큰)에 있다.

## 1. 한 줄 방향
**"골든아워의 따뜻한 그림책 속 학교."** 스타일라이즈드 저폴리 + 툰 셰이딩, 둥근 형태, 부드러운 그림자.
사실적 묘사·차가운 SF 톤·날카로운 모서리는 쓰지 않는다. 캐릭터·학교·이야기는 모두 오리지널이다.

## 2. 색 팔레트
| 역할 | 이름 | HEX | 사용처 |
|---|---|---|---|
| 주조색 | Honey | `#F6B352` | 주요 버튼, XP 막대, 강조 |
| 보조색 | Maple | `#E8743B` | 퀘스트 마크, 경고가 아닌 강조 |
| 자연 | Meadow | `#7CC36A` | 잔디, 성공, 잠금 해제 |
| 하늘 | Sky | `#7EC8E3` | 낮 하늘, 정보 |
| 밤 | Night | `#1D2440` | 밤 하늘, UI 패널 바탕 |
| 밤 강조 | Lilac | `#8E7CC3` | Bedtime, 별, 수면 타이머 |
| 종이 | Paper | `#FFF6E5` | 책·대화창 바탕 |
| 잉크 | Ink | `#2B2440` | 본문 글자 |
| 위험 | Berry | `#E0526B` | 한도 초과(빨강), 삭제 |

- 본문 글자는 Paper 위 Ink, 또는 Night 위 Paper 만 쓴다 → WCAG AA(4.5:1 이상) 보장.
- 한 화면에서 강조색은 2개까지.

## 3. 조명 프리셋 (낮/밤 순환)
| 시간 | 하늘(위→아래) | 태양/달 색 | 태양 세기 | 환경광 | 분위기 |
|---|---|---|---|---|---|
| 아침 morning | `#9ED8F0` → `#FFE9C7` | `#FFE2B0` | 1.1 | 0.65 | 상쾌, 낮은 각도 |
| 낮 day | `#6FC3EA` → `#D8F1FF` | `#FFFFFF` | 1.3 | 0.75 | 맑음 |
| 노을 sunset | `#F79A6B` → `#FFD9A0` | `#FFB070` | 1.0 | 0.55 | 골든아워(대표 이미지) |
| 밤 night | `#141A33` → `#2B3260` | `#9FB4FF` | 0.35 | 0.35 | 고요, 창문 불빛·별 |

전환은 항상 2~3초에 걸쳐 부드럽게 보간한다(뚝 끊기는 전환 금지).

## 4. 3D 스타일
- 재질: `MeshToonMaterial` 3단계 그라데이션. 텍스처는 최소화(단색 + 그라데이션), 필요 시 1024px 이하.
- 형태: 박스·캡슐·구를 조합한 둥글둥글한 저폴리. 캐릭터는 2.5등신, 큰 머리, 점 눈.
- 그림자: 부드러운 그림자 1개 광원(Medium 이상). Low 품질은 그림자 대신 발밑 원형 그림자.
- 품질: Low(그림자 없음, DPR 1) / Medium(그림자, DPR 1.5) / High(그림자 + Bloom, DPR 2).
- 외부 GLB 를 쓸 때는 CC0(Kenney, Quaternius)만, `ASSETS.md` 에 기록. 없어도 프리미티브로 실행되어야 한다.

## 5. UI 톤 (RPG 관례)
- 패널: Night 85% 불투명 + 2px Honey 테두리 + 16px 둥근 모서리. 책/대화 내용은 Paper 바탕.
- 버튼: 최소 48×48px, 아이콘 우선(글을 못 읽는 아이도 쓸 수 있게) + 짧은 영어 한 단어.
- 대화창: 왼쪽 초상화(원형), 화자 이름표, 타자 효과, 🔁 다시 듣기.
- 퀘스트 마크: 새 퀘스트 `!`(Maple), 진행 중 `?`(Honey), 잠김 🔒.
- 연출: 레벨업 = 빛 기둥 + 팡파르, 퀘스트 완료 = 위에서 내려오는 배너, 보상 = 상자 열림.
- Bedtime 화면만 예외적으로 UI 를 거의 숨긴다(글자·점수·퀴즈 없음, Lilac 저채도).

## 6. 폰트
- 게임 UI·이야기 본문: 시스템 둥근 산세리프 스택
  `ui-rounded, "SF Pro Rounded", "Nunito", "Segoe UI", system-ui, sans-serif` (웹폰트 다운로드 없음 → 오프라인 안전)
- 본문 최소 16px, 이야기 문장 22~28px, 줄 간격 1.5.
- 보호자 화면(한국어): `"Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif`

## 7. 이야기 장면 그림
- 현재는 placeholder: 장소별 2색 그라데이션 배경 + 사물 이모지(SVG, `npm run pack:art` 로 생성).
- 실제 일러스트로 교체할 때: 16:10 비율, webp, 팔레트 준수, 글자 없음(Look & Listen 은 글 없는 단계).
  `story.json` 의 `scenes[].image` 경로와 `objects[].x/y`(탭 영역, 0~100%)만 맞추면 코드 수정 없이 바뀐다.

## 8. 사운드 톤
- BGM: 장소별 부드러운 패드(현재는 Web Audio 로 합성). 밤에는 더 느리고 낮은 음.
- 효과음: 짧고 둥근 소리(실로폰·벨 느낌). 틀렸을 때 불쾌한 소리 금지 — 낮은 "통" 정도.
- 볼륨 3채널: BGM / 효과음 / 이야기 음성.
