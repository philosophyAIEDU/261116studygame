📱 휴대폰·태블릿에 설치하기

🤖 안드로이드 (Chrome)

  1. Chrome으로 게임 주소를 엽니다.
  2. 오른쪽 위 메뉴 ⋮ → 앱 설치(또는 홈 화면에 추가)를 누릅니다.
  3. 홈 화면에 생긴 School Quest 아이콘으로 실행합니다.

🍎 아이폰·아이패드 (Safari)

  1. Safari로 게임 주소를 엽니다. (다른 브라우저 앱에서는 홈 화면 추가가 안 될 수 있습니다)
  2. 아래쪽 공유 버튼(네모에서 화살표가 위로 나오는 모양)을 누릅니다.
  3. 목록을 내려 홈 화면에 추가 → 오른쪽 위 추가를 누릅니다.

아이폰은 저장 공간이 제한될 수 있어, 녹음된 이야기 소리는 필요할 때만 내려받습니다. 화면을 끈 채 이야기를 듣는 기능은 녹음 오디오가 있는 이야기에서 가장 안정적입니다.

한 번 설치하면 인터넷이 없어도 플레이할 수 있습니다. (AI 대화는 인터넷이 필요합니다)

💻 PC 설치 프로그램 (Windows · Mac)

내려받기

설치 파일 목록을 불러오는 중…

🪟 Windows 10·11

  1. 위에서 Windows 설치 프로그램 (.exe)을 내려받아 실행합니다. (회사·학교 PC처럼 관리되는 컴퓨터라면 .msi를 쓰세요)
  2. 파란 창 "Windows의 PC 보호"가 뜨면 추가 정보 → 실행을 누릅니다.
  3. 설치가 끝나면 바탕화면·시작 메뉴의 My American School Quest로 실행합니다.

아직 코드 서명 인증서가 없는 프로그램이라 처음 실행할 때 위 경고가 나옵니다. 이 사이트에서 받은 파일이라면 안전하게 진행해도 됩니다. 설치 중 화면 구성 요소(WebView2)를 내려받을 수 있으니 인터넷에 연결해 두세요.

🍏 macOS (Apple Silicon·Intel 공용)

  1. 위에서 Mac 설치 파일 (.dmg)을 내려받아 엽니다.
  2. 열린 창에서 앱 아이콘을 응용 프로그램(Applications) 폴더로 끌어 놓습니다.
  3. 앱을 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 완료를 누르고, 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기를 누른 뒤 다시 엽니다.
"손상되었기 때문에 열 수 없습니다"라고 나올 때

인터넷에서 받은 서명 없는 앱에 macOS가 붙이는 표시 때문입니다. 터미널 앱을 열고 아래 한 줄을 붙여 넣은 뒤 Enter를 누르세요.

xattr -cr "/Applications/My American School Quest.app"

그다음 앱을 다시 엽니다.

PC 설치 프로그램에서는 말하기 연습이 "녹음 후 다시 듣기"나 글자 입력으로 동작합니다. 음성 인식으로 말하기를 하려면 Chrome·Edge 브라우저에서 게임을 여세요.

🚀 처음 시작하기 — Maple Word Quest 0.3

  1. Hear apple로 소리를 확인합니다. English voice에서 영어 목소리, Voice volume에서 크기를 선택합니다.
  2. Start my level check를 눌러 단어를 듣고 그림·단어를 고릅니다. 모르면 I don’t know yet를 누릅니다. 3~12문항으로 시작 단계를 찾습니다.
  3. 탐험가를 고르고 Start my adventure를 누릅니다.

게임 속 조작 안내도 영어·아이콘으로 제공합니다. 키보드 이동이나 NPC 찾기는 필요하지 않습니다.

🔊 하루 학습 — 단어 5개로 길 열기

  1. Hear the word로 듣습니다. 필요하면 Listen slowly를 누릅니다.
  2. 들린 소리에 맞는 그림(초급) 또는 영어 단어(상급)를 고릅니다.
  3. 정답과 쉬운 영어 뜻을 보고 Next word로 넘어갑니다. 틀린 단어는 조금 뒤 다시 나옵니다.
  4. 5개를 맞히면 안개가 걷힙니다. Collect my reward로 별을 받아 탐험가 장식을 모읍니다.

4단계·96개 단어로 영어 소리와 그림·철자를 연결하는 연습입니다. 두 모험 연속 첫 정답률 80% 이상이면 더 어려운 단계로, 40% 이하이면 더 쉬운 단계로 조정합니다. 시작 진단은 공인 영어 등급 평가가 아닙니다.

📊 무엇을 배웠는지 보기

지도에서 My learning을 누릅니다. 만난 단어, 첫 시도에 맞힌 단어, 서로 다른 모험에서 3번 맞힌 단어를 구분합니다. 오답 뒤 다시 맞힌 것은 첫 정답으로 세지 않습니다.

복습은 1·3·7·14일 간격으로 돌아오며 오답은 더 빨리 연습합니다. Listen & review로 바로 복습할 수도 있습니다. 이 게임의 점수는 자유 말하기·문장 쓰기 능력을 평가하지 않습니다.

🎧 목소리와 소리

오른쪽 위 🔊에서 영어 목소리를 고르고 미리 들을 수 있습니다. 인위적인 높은 음높이를 제거했으며 영어 음성만 사용합니다. 음질은 기기의 영어 음성 엔진에 따라 다릅니다. 마이크·AI API 키는 필요하지 않습니다.

소리가 없거나 끝까지 재생되지 않으면 문제를 풀 수 없습니다. 기기 볼륨과 영어 음성 설치 상태를 확인하거나 다른 음성·Chrome·Edge·Safari로 시도해 주세요.

🔄 업데이트와 진행 기록

진행과 보상은 현재 기기·브라우저에 자동 저장됩니다. 새로고침하면 진행 중 모험을 이어갑니다. 브라우저 데이터를 지우거나 다른 기기로 이동하면 같은 기록을 자동으로 가져오지 않습니다.

웹 버전의 지도 화면에 New update! → Update now가 보이면 눌러 갱신합니다. PC 설치형은 이 페이지에서 새 설치 파일을 받아 설치할 수 있습니다. 이전 이야기·축제 저장 기록은 업데이트 때 보존됩니다.

🔒 개인정보

회원가입·광고·마이크 권한이 필요하지 않습니다. 진행은 기기 안에 저장됩니다. 선택한 TTS 음성에 따라 기기 또는 브라우저의 음성 서비스가 발음을 처리할 수 있습니다.

💬 자주 묻는 질문

무엇을 눌러야 하나요?

첫 화면은 Hear apple → Start my level check. 모험에서는 Hear the word → 그림·단어 선택 → Next word 순서입니다.

너무 쉽거나 어려워요.

모험 결과에 따라 단계가 조정됩니다. My learning 아래에서 시작 진단을 다시 할 수도 있습니다. 진행 중인 모험을 먼저 끝내 주세요.

예전 이야기 게임이 안 보여요.

0.3은 단어 듣기 모험을 기본 게임으로 바꿨습니다. 이전 이야기·축제 기록은 지우지 않지만 현재 기본 화면에서 진입을 제공하지 않습니다.
